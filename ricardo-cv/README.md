# Ricardo Pote – CV

Minimal GitHub Pages CV site modeled on the referenced example repository.

## Files

- `index.html` — embeds the CV PDF full-screen and provides a download link.
- `Ricardo_Pote_CV.pdf` — Ricardo's CV.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `cv`.
2. Upload these files to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select your default branch (usually `main`) and the `/ (root)` folder.
5. Save. GitHub will provide the public Pages URL after deployment.
